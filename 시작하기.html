Replay Rescue

꺼진 NVIDIA 즉시 리플레이를 설정한 간격으로 확인해 다시 켭니다.

앱 + 선택 사항인 Chrome 확장 프로그램
앱은 녹화 상태를 확인해 복구합니다. 확장을 연결하면 열린 탭의 도메인도 확인합니다. 외부 서버나 계정은 필요하지 않습니다.

언어 선택

상단 트레이로 최소화 옆 메뉴에서 English 또는 Korean를 선택하세요. 화면과 트레이 메뉴가 즉시 바뀌며 다음 실행에도 유지됩니다. 편집 중인 도메인과 확인 간격은 유지됩니다. 연결된 Chrome 확장도 선택한 언어를 따릅니다. 업데이트했다면 chrome://extensions에서 확장의 새로고침을 한 번 누르세요.

선택 사항: Chrome 확장 연결

  1. 이 폴더의 ReplayRescue.exe를 실행합니다. 현재 사용자에 대한 Chrome 연결과 Windows 로그인 자동 실행이 등록됩니다.
  2. Chrome 주소창에 chrome://extensions를 입력합니다.
  3. 오른쪽 위 개발자 모드를 켭니다.
  4. 압축해제된 확장 프로그램을 로드합니다를 누르고 아래 폴더를 선택합니다.
    압축을 푼 폴더\extension
  5. 상단 카드의 Chrome 상태가 연결됨으로 바뀌는지 확인합니다. 보호 사이트가 열려 있으면 상태 제목에 표시됩니다.

여러 Chrome 프로필을 사용한다면 각 프로필에 확장을 로드하세요. 시크릿 창에서도 사용할 경우 확장 세부정보의 시크릿 모드에서 허용을 켜야 합니다. 허용하지 않은 시크릿 탭이나 확장이 없는 별도 프로필의 탭은 확인할 수 없습니다.

확장 없이 사용할 때

확장을 설치하지 않았거나 비활성화해 연결이 없으면 웹 체크를 생략하고 설정한 간격으로 NVIDIA 상태를 확인해 즉시 리플레이를 다시 켭니다. 보호 사이트가 열려 있어도 복구를 시도합니다. 앱에 웹 체크 생략 여부가 표시되며, 확장이 다시 연결되면 보호 사이트 확인이 자동으로 적용됩니다. 최신 보고가 45초 넘게 중단된 확장도 미연결로 처리합니다. 앱의 일시 정지는 모든 모드에 적용됩니다.

매일 사용하는 방법

  • 기본 차단 도메인: netflix.com, coupangplay.com. 앱에서 한 줄에 도메인 하나씩 적고 목록 저장을 누르세요. 하위 도메인도 포함합니다.
  • 확장이 연결되어 있고 해당 사이트의 탭이 하나라도 열려 있으면 자동으로 켜는 작업을 멈춥니다. 비활성 탭과 최소화된 창도 확인합니다. 보호 사이트를 열었다고 앱이 녹화를 직접 끄지는 않습니다. 보호 콘텐츠로 인한 정지는 NVIDIA가 처리합니다.
  • 확인 간격: 앱의 숫자 입력란에 1~300초를 입력하고 적용을 누르세요. NVIDIA 상태를 확인하는 주기가 바로 바뀌고 다음 실행에도 유지됩니다. 기본값은 2초입니다.
  • 마지막 보호 탭을 닫으면 5초간 기다린 뒤 감시를 재개합니다. 꺼짐 상태를 다시 확인한 후 NVIDIA에 다시 켜기 단축키를 보냅니다. 기본 2초 간격에서는 보통 탭 종료 후 약 8~15초가 걸리며, 확인 간격을 길게 설정하면 복구까지 더 오래 걸릴 수 있습니다.
  • 창 최소화 또는 닫기: 트레이 아이콘만 남습니다. 원형 화살표 아이콘을 두 번 클릭하면 창이 열립니다. 트레이 우클릭 → 완전히 종료로 종료합니다.
  • Windows 자동 실행: 기본으로 켜져 있으며, 다음 로그인 때 창 없이 트레이에서 시작합니다. 앱의 Windows와 함께 시작 스위치로 해제할 수 있습니다.
  • 수동으로 즉시 리플레이를 꺼 두고 싶을 때: 앱에서 먼저 일시 정지를 누르세요. 그렇지 않으면 다시 켜집니다.

Windows 트레이 아이콘

즉시 리플레이가 켜져 있으면 초록색, 꺼져 있으면 노란색, 확인 중이거나 상태를 알 수 없으면 회색입니다. 자동 복구 일시 정지와 별도로 NVIDIA 활성 상태를 표시합니다. 사용자가 정한 확인 간격마다 갱신되며, 아이콘에 마우스를 올리면 상태 설명이 나옵니다.

Chrome 아이콘의 두 원

왼쪽 원은 즉시 리플레이 활성 여부, 오른쪽 원은 데스크톱 앱 연결 여부입니다. 초록은 활성/연결됨, 빨강은 비활성 또는 확인 불가/연결 안 됨을 나타냅니다. 마우스를 올리거나 아이콘을 누르면 상태 설명이 나옵니다. 사용자 설정 간격으로 읽은 NVIDIA 상태가 전달되며, 아이콘 갱신에는 최대 약 5초가 더 걸릴 수 있습니다.

상태 읽기

  • 즉시 리플레이 켜짐 · 녹화 시작 확인: NVIDIA의 설정과 실제 시작 기록이 일치합니다.
  • 즉시 리플레이 켜짐 · 게임 실행 대기: 데스크톱 캡처가 꺼져 있습니다. 게임을 실행하면 녹화가 시작될 수 있습니다.
  • Chrome 확장 연결 / 최신 탭 확인 대기: 현재 연결된 확장의 첫 보고 또는 변경된 도메인 정책을 기다립니다. 확장 연결 자체가 없거나 보고가 만료되면 웹 체크를 생략하고 복구합니다.
  • 설정 켜짐 · 실제 녹화 시작 확인 대기: NVIDIA 설정은 켜졌지만 녹화 시작 기록이 아직 없습니다. 앱은 이를 실제 녹화 성공으로 표시하지 않습니다.

확인 시험

  1. 보호 사이트 탭을 모두 닫고 NVIDIA 오버레이에서 즉시 리플레이를 꺼 보세요.
  2. 앱이 다시 켜는지 확인합니다. 이 PC의 전환 단축키는 Alt+Shift+F10입니다.
  3. Netflix 탭을 열어 앱이 대기하는지 확인합니다. 탭을 닫고 감시가 재개되는지 확인하세요.
  4. 게임에서 Alt+F10으로 테스트 클립을 저장해 영상과 소리를 확인합니다.

문제가 생기면

앱의 진단 저장 또는 전체 로그를 사용하세요. 앱은 도메인 일치 결과와 상태 변화를 로컬 data 폴더에 기록합니다. 전체 방문 URL, 페이지 내용, 쿠키는 수집하지 않습니다. NVIDIA 오버레이를 꺼 둔 경우 켜야 합니다. NVIDIA App 업데이트로 내부 상태 형식이 바뀌면 앱 수정이 필요할 수 있습니다.

실행 폴더를 옮기면 새 위치에서 EXE를 다시 실행하고 자동 실행 스위치를 껐다 켜세요. Chrome 확장도 새 폴더에서 다시 로드해야 합니다. 앱과 extension 폴더를 함께 보관하세요.

제거

자동 실행 스위치 끄기 → 트레이에서 완전히 종료 → Chrome 확장 삭제 순서로 제거하세요. uninstall.ps1은 이 앱의 자동 실행과 Chrome 연결 등록만 제거하고 파일과 로그는 보존합니다.
