Replay Rescue

Automatically re-enable NVIDIA Instant Replay on Windows.

Run locally. Use Chrome protection when you need it.
The desktop app monitors Instant Replay and restores it when it turns off. The optional Chrome extension pauses recovery for protected sites. No remote account or service is required.

Start the app

  1. Extract the full ZIP into a writable folder. Run ReplayRescue.exe and keep the other files alongside it.
  2. Select English or Korean next to Minimize to tray. The choice is saved.
  3. Set a Check interval from 1 to 300 seconds and select Apply. Longer intervals may take longer to restore replay.

The app requires Windows 10/11 x64, .NET Framework 4.8, and an NVIDIA GPU with NVIDIA App and its overlay. No .NET SDK or Python installation is needed. First run registers its local Chrome bridge and enables Windows login startup for your user.

Optional: pause for protected websites

  1. Open chrome://extensions in Chrome.
  2. Enable Developer mode, select Load unpacked, and choose the included extension folder.
  3. Check that the desktop app shows Chrome as connected.
  4. Under Protected sites, enter one domain per line, then select Save sites. Subdomains are included. Defaults: netflix.com and coupangplay.com.

When no extension is connected, the app displays Site check off and continues recovery even while websites are open. Reports older than 45 seconds are treated as disconnected. Connecting the extension restores website checks automatically.

Use the extension in every Chrome profile you want it to check. For incognito tabs, enable Allow in incognito in the extension's details. Other browsers and profiles without the extension are not inspected. The extension compares URLs locally; it does not send page content or full URLs to the desktop app.

Read the status

  • NVIDIA: the enabled/disabled Instant Replay setting.
  • Recording: recording state from NVIDIA's runtime log, separate from the enabled setting.
  • Waiting for game capture: with desktop capture off, replay can be enabled while waiting for a game.
  • Chrome: connection and site-check status. The extension's left light shows Instant Replay; the right light shows the desktop connection.

Use the tray

  • Green: replay enabled. Yellow: replay disabled. Gray: status unknown.
  • Closing or minimizing the window keeps monitoring in the tray. Double-click the tray icon to reopen it.
  • Use Pause if you want to leave Instant Replay off. Use the tray's Exit Replay Rescue command to quit completely.
  • Start with Windows launches the app in the tray when you sign in.

Update inside the app

Open Updates at the bottom of the window or App updates in the tray menu. Automatic checks are enabled by default: a due check runs about 30 seconds after startup, then at least 24 hours apart. You can turn automatic checks off and check manually.

Choose Install and restart when a newer stable release is available. Save any pending edits first. The app downloads from GitHub, verifies the ZIP's SHA256 and EXE version, backs up the previous files, and restarts. Saved settings and the data folder are preserved. File replacement failures restore the previous files; backups stay in data/updates/. Reload the Chrome extension if its code was updated.

Checks use GitHub over HTTPS and do not upload settings, protected domains, or logs. Checking alone does not install or restart. Version 1.3.0 and earlier need one manual ZIP update to gain this feature.

Manual update or move

Exit from the tray before replacing files. Keep the existing data folder to preserve settings. Reload the extension at chrome://extensions after updating it. If Chrome keeps the EXE open, disable the extension during replacement, then enable it again. When moving folders, run the EXE at the new path, switch startup off and on, and load the extension from the new folder.

Troubleshooting

Use Save diagnostics or Full log. Make sure the NVIDIA overlay is available and an Instant Replay toggle shortcut is configured. The app reads your shortcut instead of guessing it. It does not patch NVIDIA files or drivers. NVIDIA updates can change internal status formats. Verify saved video and audio in your own game; an enabled setting alone does not prove a working recording.

Uninstall

Turn off Start with Windows, exit from the tray, and remove the Chrome extension. uninstall.ps1 removes this folder's registrations without deleting settings or logs.
